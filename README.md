# wallet-exit-kit

Read-only toolkit and agent skills for leaving DeFi positions safely. It scans wallets across EVM chains, triages approvals, writes revoke and exit check cards with simulation, and tracks waiting periods and deadlines. The user always signs in their own wallet. Nothing here holds keys, signs, or broadcasts.

GitLab is the canonical repository: https://gitlab.com/aa22396584/wallet-exit-kit . Issues and merge requests go there.
